# Resource button icons

- arXiv: https://github.com/simple-icons/simple-icons/blob/develop/icons/arxiv.svg
- Code (GitHub): https://github.com/simple-icons/simple-icons/blob/develop/icons/github.svg
- Model (Hugging Face): https://github.com/simple-icons/simple-icons/blob/develop/icons/huggingface.svg
- Dataset: locally drawn database cylinder SVG.
- BibTeX: locally drawn quotation-mark SVG.

Brand icons are embedded as inline SVG paths and inherit the button colour. Icons are decorative; each button has a visible text label. arXiv, Model and Dataset have no provided destination yet and are shown as unavailable. Code targets the repository's main branch; BibTeX targets the existing citation section.
